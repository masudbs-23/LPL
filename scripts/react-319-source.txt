১. React কী?
React হলো ফেসবুক তৈরি করা একটি JavaScript লাইব্রেরি যা ইউজার ইন্টারফেস (UI) বানানোর জন্য ব্যবহৃত হয়। এটি কম্পোনেন্ট-ভিত্তিক এবং ডিক্লারেটিভ। অর্থাৎ, আপনি বলেন "আমি এই UI দেখতে চাই" আর React তা DOM-এ এনে দেয়।

২. React-এর ইতিহাস কী?
২০১১: ফেসবুকের নিউজফিডে FaxJS নামে প্রোটোটাইপ।

২০১৩: প্রথম ওপেন সোর্স রিলিজ (JSConf US)।

২০১৫: React Native আসে।

২০১৭: React Fiber রি-রাইট (ভার্চুয়াল DOM-এর নতুন অ্যালগরিদম)।

২০১৯: Hooks আসে (useState, useEffect)।

৩. React-এর প্রধান ফিচারগুলো কী কী?
JSX (JavaScript-এ HTML লেখা)

ভার্চুয়াল DOM (দ্রুত রেন্ডার)

কম্পোনেন্ট-ভিত্তিক (পুনঃব্যবহারযোগ্য ব্লক)

ওয়ান-ওয়ে ডেটা বাইন্ডিং (ডেটা শুধু উপরে থেকে নিচে যায়)

React Hooks (স্টেট ও লাইফসাইকেল ফাংশনাল কম্পোনেন্টে)

৪. JSX কী?
JSX হলো JavaScript XML – এটি JavaScript-এর সিনট্যাক্স এক্সটেনশন যা দেখতে HTML-এর মতো। ব্রাউজার বুঝে না, বাবেল ট্রান্সপাইল করে React.createElement() কল করে।

jsx
const element = <h1>Hello</h1>; // JSX
৫. Element ও Component-এর মধ্যে পার্থক্য কী?
Element: একটি সাধারণ অবজেক্ট যা DOM নোড বা অন্য কম্পোনেন্টকে বর্ণনা করে। এটি ইমিউটেবল।

Component: একটি ফাংশন বা ক্লাস যা প্রপস নিয়ে Element রিটার্ন করে।

৬. React-এ কীভাবে কম্পোনেন্ট তৈরি করেন?
ফাংশনাল কম্পোনেন্ট:

jsx
function Greeting() { return <h1>Hi</h1>; }
ক্লাস কম্পোনেন্ট:

jsx
class Greeting extends React.Component {
  render() { return <h1>Hi</h1>; }
}
৭. কখন ক্লাস কম্পোনেন্টের বদলে ফাংশনাল কম্পোনেন্ট ব্যবহার করবেন?
React 16.8-এর পর Hooks আসায় প্রায় সব ক্ষেত্রেই ফাংশনাল কম্পোনেন্ট ব্যবহার করা ভালো। ক্লাস কম্পোনেন্ট দরকার শুধুমাত্র যদি আপনি পুরনো কোডে Error Boundaries ব্যবহার করেন (কারণ Hooks দিয়ে এখনো error boundary বানানো যায় না)।

৮. Pure Components কী?
Pure Components হলো সেই কম্পোনেন্ট যা shallow props/state তুলনা করে এবং যদি কোনো পরিবর্তন না থাকে তবে রি-রেন্ডার হয় না। এটি Performance Optimization-এর জন্য।

৯. React-এ state কী?
State হলো একটি কম্পোনেন্টের মালিকানাধীন ডেটা যা সময়ের সাথে পরিবর্তিত হতে পারে। এটি প্রাইভেট এবং কম্পোনেন্ট নিজেই নিয়ন্ত্রণ করে।

jsx
const [count, setCount] = useState(0);
১০. props কী?
Props (Properties) হলো ইমিউটেবল ডেটা যা প্যারেন্ট কম্পোনেন্ট থেকে চাইল্ডে পাঠানো হয়। চাইল্ড props পরিবর্তন করতে পারে না।

১১. state ও props-এর মধ্যে পার্থক্য কী?
বৈশিষ্ট্য	state	props
পরিবর্তনযোগ্য?	হ্যাঁ (setState)	না (ইমিউটেবল)
কে নিয়ন্ত্রণ করে?	নিজের কম্পোনেন্ট	প্যারেন্ট কম্পোনেন্ট
ব্যবহার	ইন্টারনাল ডেটা	কনফিগারেশন
১২. HTML ও React ইভেন্ট হ্যান্ডলিং-এর পার্থক্য কী?
HTML-এ ইভেন্ট নাম ছোট হাতের (onclick), React-এ camelCase (onClick)। HTML-এ ফাংশন কল স্ট্রিং হিসেবে, React-এ ফাংশন রেফারেন্স। React-এ ইভেন্ট বাবলিং বন্ধ করতে preventDefault() দরকার।

১৩. Synthetic Events কী?
Synthetic Event হলো React-এর ক্রস-ব্রাউজার র‍্যাপার যা নেটিভ ব্রাউজার ইভেন্টকে ঘিরে তৈরি। এটি সব ব্রাউজারে একই আচরণ নিশ্চিত করে।

১৪. Inline Conditional Expressions কী?
JSX-এর ভেতর শর্ত বসানোর উপায়:

Ternary Operator: {isLoggedIn ? <Logout /> : <Login />}

Logical &&: {isLoading && <Spinner />}

১৫. "key" prop কী এবং অ্যারের এলিমেন্টে এর সুবিধা কী?
Key React কে বলে দেয় কোন এলিমেন্ট পরিবর্তিত, যোগ বা সরানো হয়েছে। এটি পুনঃব্যবহার ও রি-অর্ডারিং দ্রুত করে। ইনডেক্স কী ব্যবহার না করে ইউনিক আইডি ব্যবহার করবেন।

১৬. Virtual DOM কী?
Virtual DOM হলো রিয়েল DOM-এর একটি লাইটওয়েট JavaScript অবজেক্ট রেপ্লিকা। এটি মেমোরিতে থাকে এবং পরিবর্তনগুলো হিসাব করে, তারপর শুধু প্রয়োজনীয় অংশ রিয়েল DOM-এ আপডেট করে।

১৭. Virtual DOM কীভাবে কাজ করে?
UI-তে কোনো পরিবর্তন হলে নতুন ভার্চুয়াল DOM তৈরি হয়।

পুরনো ভার্চুয়াল DOM-এর সাথে নতুন ভার্চুয়াল DOM-এর তুলনা (diffing) হয়।

শুধু পরিবর্তিত অংশ রিয়েল DOM-এ আপডেট হয় (reconciliation)।

১৮. Shadow DOM ও Virtual DOM-এর পার্থক্য কী?
Shadow DOM	Virtual DOM
ব্রাউজার ফিচার (Web Components)	React-এর ম্যানেজড কপি
CSS ও মার্কপ এনক্যাপসুলেট করে	শুধু পারফরম্যান্সের জন্য ডিফিং
১৯. React Fiber কী?
React Fiber হলো React v16-তে আসা কোর অ্যালগরিদমের পুনর্লিখন। এটি রেন্ডারিং কাজকে ছোট ইউনিটে ভাগ করে এবং উচ্চ-প্রাধান্যের কাজ আগে করে (যেমন অ্যানিমেশন)।

২০. React Fiber-এর প্রধান লক্ষ্য কী?
ইন্টারাপ্টেবল রেন্ডারিং (অন্যান্য কাজের জন্য থামানো যাবে)

প্রাধান্য ভিত্তিক আপডেট

কনকারেন্ট রেন্ডারিং সম্ভব করা

২১. Controlled Components কী?
যেখানে ফর্ম এলিমেন্টের মান React state দ্বারা নিয়ন্ত্রিত হয়। প্রতিটি টাইপে onChange ইভেন্টে state আপডেট হয়।

jsx
<input value={name} onChange={e => setName(e.target.value)} />
২২. Uncontrolled Components কী?
যেখানে ফর্ম এলিমেন্ট তার নিজের internal state রাখে (DOM-এর মতো)। মান পেতে ref ব্যবহার করি।

jsx
<input ref={inputRef} />
২৩. createElement ও cloneElement-এর পার্থক্য কী?
createElement(type, props, ...children) → নতুন React এলিমেন্ট তৈরি করে।

cloneElement(element, newProps, ...children) → বিদ্যমান এলিমেন্ট কপি করে নতুন props মার্জ করে।

২৪. Lifting State Up কী?
যখন একাধিক চাইল্ড কম্পোনেন্টের একই ডেটার প্রয়োজন হয়, তখন সেই ডেটা কমন প্যারেন্টে রেখে প্রপস আকারে পাঠানো। একে "স্টেট উত্তোলন" বলে।

২৫. Higher-Order Components (HOC) কী?
HOC হলো একটি ফাংশন যা একটি কম্পোনেন্ট নিয়ে একটি নতুন কম্পোনেন্ট রিটার্ন করে। এটি লজিক রিইউজের জন্য।

jsx
const EnhancedComponent = higherOrderComponent(WrappedComponent);
২৬. children prop কী?
children হলো একটি বিশেষ prop যা কম্পোনেন্টের ওপেনিং ও ক্লোজিং ট্যাগের মধ্যের সবকিছু ধারণ করে।

jsx
<Card> <h1>Title</h1> </Card> // এখানে <h1> হলো children
২৭. React-এ মন্তব্য কীভাবে লিখেন?
JSX-এর বাইরে: // comment বা /* comment */

JSX-এর ভেতর: {/* comment */}

২৮. Reconciliation কী?
Reconciliation হলো React-এর ডিফিং অ্যালগরিদম যা দুইটি ট্রির তুলনা করে কোন নোড পরিবর্তিত হয়েছে তা বের করে এবং শুধু সেই অংশ রিয়েল DOM-এ আপডেট করে।

২৯. lazy ফাংশন কি named exports সমর্থন করে?
না। React.lazy() শুধু default export সমর্থন করে। named export দরকার হলে মিডলম্যান মডিউল তৈরি করুন।

৩০. React কেন class অ্যাট্রিবিউটের বদলে className ব্যবহার করে?
কারণ class JavaScript-এ রিজার্ভড কীওয়ার্ড। JSX বাবেল ট্রান্সপাইলের সময় className-কে class-এ রূপান্তর করে।

৩১. Fragments কী?
Fragments (<></> বা <React.Fragment>) একটি গ্রুপিং এলিমেন্ট যা অতিরিক্ত DOM নোড ছাড়াই একাধিক এলিমেন্ট রিটার্ন করতে দেয়।

৩২. Fragments কেন container div-এর চেয়ে ভালো?
কম DOM নোড → দ্রুত রেন্ডার

CSS ফ্লেক্স/গ্রিড লেআউট ভাঙে না

ডেভ টুলস পরিষ্কার থাকে

৩৩. Portals কী?
Portals একটি কম্পোনেন্টের JSX-কে প্যারেন্ট ট্রির বাইরে অন্য DOM নোডে রেন্ডার করার উপায় দেয়। মোডাল, টুলটিপের জন্য দারুণ।

jsx
ReactDOM.createPortal(child, domNode)
৩৪. Stateless Components কী?
যেসব কম্পোনেন্টের কোনো state নেই, শুধু props নিয়ে UI রেন্ডার করে। এরা প্রায়ই Presentational Components।

৩৫. Stateful Components কী?
যেসব কম্পোনেন্টের state আছে এবং তারা ডেটা পরিবর্তন করে বা লজিক ধারণ করে। এরা Container Components বা স্মার্ট কম্পোনেন্ট।

৩৬. React-এ props-এ কীভাবে ভ্যালিডেশন প্রয়োগ করবেন?
prop-types প্যাকেজ ব্যবহার করে:

jsx
MyComponent.propTypes = {
  name: PropTypes.string.isRequired
}
৩৭. React-এর সুবিধাগুলো কী কী?
দ্রুত: ভার্চুয়াল DOM-এর জন্য

মডুলার: ছোট ছোট কম্পোনেন্ট

সহজ ডিবাগ (ওয়ান-ওয়ে ডেটা ফ্লো)

মোবাইল অ্যাপ (React Native)

বড় কমিউনিটি

৩৮. React-এর সীমাবদ্ধতা কী কী?
শুধু UI (পূর্ণাঙ্গ ফ্রেমওয়ার্ক নয়, রাউটিং/স্টেট ম্যানেজমেন্ট আলাদা লাগে)

JSX শিখতে হবে

দ্রুত পরিবর্তনশীল ইকোসিস্টেম

SEO ফ্রেন্ডলি না (SSR লাগে, যেমন Next.js)

৩৯. স্ট্যাটিক টাইপ চেকিংয়ের জন্য প্রস্তাবিত উপায়গুলো কী?
TypeScript (মাইক্রোসফট)

Flow (ফেসবুক)

৪০. react-dom প্যাকেজের ব্যবহার কী?
react-dom React কম্পোনেন্টকে ব্রাউজারের DOM-এ রেন্ডার করার জন্য পদ্ধতি দেয়। যেমন:

render()

hydrate() (SSR-এর জন্য)

createPortal()

৪১. ReactDOMServer কী?
এটি সার্ভার-সাইডে React কম্পোনেন্টকে HTML স্ট্রিং বা স্ট্রিম এ রূপান্তর করে (SSR-এর জন্য)।

৪২. React-এ innerHTML কীভাবে ব্যবহার করবেন?
dangerouslySetInnerHTML prop ব্যবহার করে, কিন্তু সতর্ক থাকবেন (XSS আক্রমণ হতে পারে)।

jsx
<div dangerouslySetInnerHTML={{__html: htmlString}} />
৪৩. React-এ কীভাবে স্টাইল প্রয়োগ করবেন?

CSS ক্লাস: className="btn"

CSS-in-JS (styled-components)

৪. JSX কী?
JSX হল JavaScript XML - জাভাস্ক্রিপ্টের সিনট্যাক্স এক্সটেনশন যা দেখতে HTML-এর মতো। ব্রাউজার বুঝে না, বাবেল ট্রান্সপাইল করে React.createElement()-এ।

ক্লাস: class Greeting extends React.Component { render() { return <h1>Hi</h1>; } }

৭. ক্লাস কম্পোনেন্টের পরিবর্তে ফাংশনাল কম্পোনেন্ট কখন ব্যবহার করবেন?
হুকস আসার পর প্রায় সব সময়ই ফাংশনাল কম্পোনেন্ট ব্যবহার করবেন। ক্লাস দরকার শুধু এরর বাউন্ডারির জন্য (এখনও হুকসে নেই)।

৮. পিওর কম্পোনেন্ট কী?
যে কম্পোনেন্ট shallow তুলনা করে প্রপস ও স্টেটের - কোনো পরিবর্তন না থাকলে রি-রেন্ডার হয় না। পারফরম্যান্স বুস্টার।

৯. রিয়্যাক্টে স্টেট কী?
স্টেট হলো কম্পোনেন্টের নিজস্ব ডেটা যা পরিবর্তনশীল। useState বা this.setState দিয়ে নিয়ন্ত্রণ করা হয়।

১০. প্রপস কী?
প্রপস হল ইমিউটেবল ডেটা যা প্যারেন্ট থেকে চাইল্ডে যায়। চাইল্ড কখনো প্রপস পরিবর্তন করতে পারে না।

১১. স্টেট ও প্রপসের মধ্যে পার্থক্য কী?
বিষয়	স্টেট	প্রপস

মালিকানা	নিজের	প্যারেন্ট
ব্যবহার	অভ্যন্তরীণ ডেটা	কনফিগারেশন
১২. HTML ও রিয়্যাক্ট ইভেন্ট হ্যান্ডলিংয়ের পার্থক্য কী?
HTML: onclick="handle()" (স্ট্রিং, ছোট হাতের)
রিয়্যাক্ট: onClick={handle} (ফাংশন রেফারেন্স, ক্যামেলকেস)

১৩. সিনথেটিক ইভেন্ট কী?
রিয়্যাক্টের ক্রস-ব্রাউজার র‍্যাপার যা সব ব্রাউজারে নেটিভ ইভেন্টের মতো কাজ করে।

১৪. ইনলাইন কন্ডিশনাল এক্সপ্রেশন কী?
JSX-এর ভেতর শর্ত বসানোর উপায়: টার্নারি (? :) বা লজিক্যাল (&&)

১৫. "key" প্রপ কী এবং অ্যারের এলিমেন্টে এর সুবিধা কী?
Key রিয়্যাক্টকে চিহ্নিত করতে সাহায্য করে কোন এলিমেন্ট পরিবর্তিত হয়েছে। ইউনিক আইডি ব্যবহার করুন, ইনডেক্স নয়।

১৬. ভার্চুয়াল DOM কী?
ভার্চুয়াল DOM হল রিয়েল DOM-এর হালকা জাভাস্ক্রিপ্ট কপি যা মেমোরিতে থাকে।

১৭. ভার্চুয়াল DOM কীভাবে কাজ করে?
পরিবর্তন → নতুন ভার্চুয়াল DOM → ডিফিং (তুলনা) → শুধু পরিবর্তিত অংশ রিয়েল DOM-এ আপডেট

১৮. শ্যাডো DOM ও ভার্চুয়াল DOM-এর পার্থক্য কী?
শ্যাডো DOM ব্রাউজারের ওয়েব কম্পোনেন্ট ফিচার (এনক্যাপসুলেশন), ভার্চুয়াল DOM রিয়্যাক্টের পারফরম্যান্স টেকনিক।

১৯. রিয়্যাক্ট ফাইবার কী?
রিয়্যাক্ট ১৬-তে আসা কোর অ্যালগরিদমের পুনর্লিখন যা রেন্ডারিং কাজকে ছোট ইউনিটে ভাগ করে এবং প্রাধান্য দেয়।

২০. রিয়্যাক্ট ফাইবারের প্রধান লক্ষ্য কী?
থামানো যায় এমন রেন্ডারিং

প্রাধান্য-ভিত্তিক আপডেট

কনকারেন্ট রেন্ডারিং

২১. কন্ট্রোল্ড কম্পোনেন্ট কী?
যেখানে ফর্ম এলিমেন্টের মান রিয়্যাক্ট স্টেট দ্বারা নিয়ন্ত্রিত হয়। onChange দিয়ে আপডেট।

২২. আনকন্ট্রোল্ড কম্পোনেন্ট কী?
যেখানে ফর্ম এলিমেন্ট তার নিজস্ব DOM স্টেট রাখে। মান পেতে ref ব্যবহার হয়।

২৩. createElement ও cloneElement-এর পার্থক্য কী?
createElement নতুন এলিমেন্ট বানায়, cloneElement বিদ্যমান এলিমেন্টের কপি করে নতুন প্রপস মার্জ করে।

২৪. লিফটিং স্টেট আপ কী?
একাধিক চাইল্ডের একই ডেটা দরকার হলে তা কমন প্যারেন্টে রেখে প্রপস আকারে পাঠানো।

২৫. হায়ার-অর্ডার কম্পোনেন্ট (HOC) কী?
ফাংশন যা একটি কম্পোনেন্ট নিয়ে একটি নতুন কম্পোনেন্ট রিটার্ন করে। লজিক রিইউজের জন্য।

২৬. children প্রপ কী?
স্পেশাল প্রপ যা কম্পোনেন্টের ট্যাগের ভেতরের সবকিছু ধারণ করে।

২৭. রিয়্যাক্টে মন্তব্য কীভাবে লিখেন?
JSX-এর ভেতর: {/* মন্তব্য */}
JSX-এর বাইরে: // মন্তব্য

২৮. রিকনসিলিয়েশন কী?
রিয়্যাক্টের ডিফিং অ্যালগরিদম যা দুইটি ট্রির তুলনা করে পরিবর্তিত অংশ বের করে।

২৯. lazy ফাংশন কি named exports সমর্থন করে?
না। শুধু ডিফল্ট এক্সপোর্ট সমর্থন করে।

৩০. রিয়্যাক্ট কেন class অ্যাট্রিবিউটের বদলে className ব্যবহার করে?
কারণ class জাভাস্ক্রিপ্টের রিজার্ভড কীওয়ার্ড।

৩১. ফ্র্যাগমেন্টস কী?
<></> বা <React.Fragment> - অতিরিক্ত DOM নোড ছাড়া একাধিক এলিমেন্ট রিটার্ন করতে দেয়।

৩২. ফ্র্যাগমেন্টস কেন কন্টেইনার div-এর চেয়ে ভালো?

৩৩. পোর্টালস কী?
কম্পোনেন্টের JSX-কে প্যারেন্ট ট্রির বাইরে অন্য DOM নোডে রেন্ডার করার উপায়। মোডালের জন্য দারুণ।

৩৪. স্টেটলেস কম্পোনেন্ট কী?
যেসব কম্পোনেন্টের কোনো স্টেট নেই, শুধু প্রপস নিয়ে UI রেন্ডার করে।

৩৫. স্টেটফুল কম্পোনেন্ট কী?
যেসব কম্পোনেন্টের স্টেট আছে এবং ডেটা পরিবর্তন করতে পারে।

৩৬. রিয়্যাক্টে প্রপসে কীভাবে ভ্যালিডেশন প্রয়োগ করবেন?
prop-types প্যাকেজ ব্যবহার করে: MyComponent.propTypes = { name: PropTypes.string }

৩৭. রিয়্যাক্টের সুবিধাগুলো কী কী?

৩৮. রিয়্যাক্টের সীমাবদ্ধতা কী কী?

৩৯. স্ট্যাটিক টাইপ চেকিংয়ের জন্য প্রস্তাবিত উপায়গুলো কী?
টাইপস্ক্রিপ্ট বা ফ্লো (ফেসবুকের টুল)।

৪০. react-dom প্যাকেজের ব্যবহার কী?
রিয়্যাক্ট কম্পোনেন্টকে ব্রাউজারের DOM-এ রেন্ডার করা, হাইড্রেট করা, পোর্টাল বানানো।

৪১. ReactDOMServer কী?
সার্ভার-সাইডে রিয়্যাক্ট কম্পোনেন্টকে HTML স্ট্রিং বা স্ট্রিমে রূপান্তর করে (SSR-এর জন্য)।

৪২. রিয়্যাক্টে innerHTML কীভাবে ব্যবহার করবেন?
dangerouslySetInnerHTML প্রপ ব্যবহার করে: <div dangerouslySetInnerHTML={{__html: htmlString}} />

৪৩. রিয়্যাক্টে কীভাবে স্টাইল প্রয়োগ করবেন?
ইনলাইন স্টাইল (style={{color: 'red'}}), CSS ক্লাস (className="btn"), বা CSS-in-JS।

৪৪. রিয়্যাক্টে ইভেন্টগুলি কীভাবে আলাদা?
ক্যামেলকেস, ফাংশন পাস, return false কাজ করে না, preventDefault() দিতে হয়।

৪৫. কী হিসেবে ইনডেক্স ব্যবহারের প্রভাব কী?
ভুল ম্যাচিং, কম পারফরম্যান্স, অ্যানিমেশন ভাঙা।

৪৬. কীভাবে শর্তসাপেক্ষে কম্পোনেন্ট রেন্ডার করবেন?
if/else, টার্নারি, লজিক্যাল &&, অথবা IIFE দিয়ে।

৪৭. DOM এলিমেন্টে প্রপস ছড়িয়ে দিতে কেন সতর্ক থাকবেন?
কাস্টম প্রপস DOM এলিমেন্টে গেলে রিয়্যাক্ট unknown prop warning দেয়।

৪৮. কীভাবে একটি কম্পোনেন্ট মেমোয়েজ করবেন?
ফাংশনাল: React.memo()
ক্লাস: PureComponent বা shouldComponentUpdate

৪৯. কীভাবে সার্ভার-সাইড রেন্ডারিং (SSR) ইমপ্লিমেন্ট করবেন?
renderToString() দিয়ে HTML বানান, ক্লায়েন্টে hydrate() করেন। Next.js ব্যবহার করা ভালো।

৫০. রিয়্যাক্টে প্রোডাকশন মোড কীভাবে এনাবল করবেন?
CRA: npm run build
Webpack: mode: 'production'

৫১. হুকস কি রেন্ডার প্রপস এবং HOC প্রতিস্থাপন করে?
বেশিরভাগ ক্ষেত্রেই হাঁ, কিন্তু কিছু জটিল প্যাটার্নে এখনও এদের দরকার হতে পারে।

৫২. সুইচিং কম্পোনেন্ট কী?
কম্পোনেন্ট যা একাধিক কম্পোনেন্টের মধ্যে শর্তসাপেক্ষে রেন্ডার করে।

৫৩. রিয়্যাক্ট মিক্সিনস কী?
পুরনো পদ্ধতি (React.createClass)-তে লজিক রিইউজের উপায়। এখন বাতিল।

৫৪. রিয়্যাক্টে সমর্থিত পয়েন্টার ইভেন্টগুলো কী কী?
onPointerDown, onPointerMove, onPointerUp, onPointerCancel ইত্যাদি।

৫৫. কম্পোনেন্টের নাম কেন বড় হাতের অক্ষর দিয়ে শুরু হওয়া উচিত?
JSX ছোট হাতের ট্যাগকে HTML এলিমেন্ট ধরে, বড় হাতেরকে কম্পোনেন্ট ধরে।

৫৬. রিয়্যাক্ট v16-এ কি কাস্টম DOM অ্যাট্রিবিউট সমর্থিত?
হাঁ। অজানা অ্যাট্রিবিউট DOM-এ যায় (কিছু রিজার্ভড ছাড়া)।

৫৭. JSX-এর ভেতর কীভাবে লুপ করবেন?
map() ফাংশন ব্যবহার করে: {items.map(item => <div key={item.id}>{item.name}</div>)}

৫৮. অ্যাট্রিবিউট কোটেশনের ভেতর কীভাবে প্রপস অ্যাক্সেস করবেন?
টেমপ্লেট লিটারেল: className={btn-${type}}

৫৯. রিয়্যাক্ট প্রপটাইপ অ্যারে উইথ শেপ কী?
PropTypes.arrayOf(PropTypes.shape({...})) - নির্দিষ্ট আকৃতির অবজেক্টের অ্যারে ভ্যালিডেট করে।

৬০. কীভাবে শর্তসাপেক্ষে ক্লাস অ্যাট্রিবিউট প্রয়োগ করবেন?
className={condition ? 'active' : 'inactive'} অথবা classnames লাইব্রেরি।

৬১. রিয়্যাক্ট ও ReactDOM-এর মধ্যে পার্থক্য কী?
রিয়্যাক্ট হল কোর লাইব্রেরি (কম্পোনেন্ট, স্টেট), ReactDOM হল DOM-এ রেন্ডার করার টুল।

৬২. ReactDOM কেন রিয়্যাক্ট থেকে আলাদা?
যাতে রিয়্যাক্টকে অন্যান্য প্ল্যাটফর্মে (React Native, VR) ব্যবহার করা যায়।

৬৩. রিয়্যাক্টে label এলিমেন্ট কীভাবে ব্যবহার করবেন?
স্বাভাবিক HTML-এর মতো, তবে htmlFor অ্যাট্রিবিউট ব্যবহার করবেন (কারণ for রিজার্ভড কীওয়ার্ড)।

৬৪. কীভাবে একাধিক ইনলাইন স্টাইল অবজেক্ট একত্রিত করবেন?
style={{...style1, ...style2}} (স্প্রেড অপারেটর) বা Object.assign() দিয়ে।

৬৫. ব্রাউজার রিসাইজ হলে কীভাবে ভিউ রি-রেন্ডার করবেন?
window.addEventListener('resize') ইভেন্ট লিসেনার বসান, স্টেট আপডেট করলে রি-রেন্ডার হবে।

৬৬. রিয়্যাক্ট দিয়ে কীভাবে JSON প্রিটি-প্রিন্ট করবেন?
<pre>{JSON.stringify(data, null, 2)}</pre>

৬৭. রিয়্যাক্টে কেন প্রপস আপডেট করতে পারেন না?
প্রপস ইমিউটেবল - এটি প্যারেন্ট থেকে সন্তানের দিকে শুধু পঠনযোগ্য ডেটা।

৬৮. পেজ লোডে কীভাবে ইনপুট এলিমেন্টে ফোকাস করবেন?
useRef হুক ব্যবহার করে inputRef.current.focus() (useEffect-এর ভেতর)।

৬৯. ব্রাউজারে রানটাইমে কীভাবে রিয়্যাক্টের ভার্সন খুঁজবেন?
কনসোলে টাইপ করুন: React.version (যেখানে React গ্লোবালে আছে) বা DevTools-এ দেখুন।

৭০. রিয়্যাক্ট রাউটারের জন্য কীভাবে গুগল অ্যানালিটিক্স যোগ করবেন?
useEffect দিয়ে লোকেশন পরিবর্তন ট্র্যাক করে GA ইভেন্ট পাঠান।

৭১. রিয়্যাক্টে ইনলাইন স্টাইলে কীভাবে ভেন্ডর প্রিফিক্স প্রয়োগ করবেন?
রিয়্যাক্ট স্বয়ংক্রিয়ভাবে কিছু প্রিফিক্স করে, বাকিগুলো ম্যানুয়ালি দিতে হবে (যেমন WebkitTransition)।

৭২. রিয়্যাক্ট ও ES6 ব্যবহার করে কীভাবে কম্পোনেন্ট ইম্পোর্ট ও এক্সপোর্ট করবেন?
export default MyComponent;
import MyComponent from './MyComponent';

৭৩. রিয়্যাক্ট কম্পোনেন্ট নামকরণের ব্যতিক্রমগুলো কী কী?
DOM ট্যাগ (div, span) ছোট হাতের, কম্পোনেন্ট বড় হাতের। ডট নোটেশন (MyComponent.Sub) ব্যবহার করা যায়।

৭৪. প্লেইন রিয়্যাক্টে কি async/await ব্যবহার করা সম্ভব?
হাঁ। এটি জাভাস্ক্রিপ্ট ফিচার, রিয়্যাক্টের সাথে সম্পর্কিত নয়। useEffect-এর ভেতর ব্যবহার করতে পারেন।

৭৫. সাধারণ ফোল্ডার কাঠামো কী কী?

রিয়্যাক্ট রাউটার (React Router) - ৭৯ থেকে ৮৯
৭৯. রিয়্যাক্ট রাউটার কী?
রিয়্যাক্ট অ্যাপ্লিকেশনে ক্লায়েন্ট-সাইড রাউটিং করার জন্য জনপ্রিয় লাইব্রেরি। SPA-তে পৃষ্ঠা রিলোড ছাড়া URL পরিবর্তন করে।

৮০. রিয়্যাক্ট রাউটার কীভাবে হিস্ট্রি লাইব্রেরি থেকে আলাদা?
হিস্ট্রি লাইব্রেরি নিচের স্তরে URL ম্যানেজ করে, রিয়্যাক্ট রাউটার এটি ব্যবহার করে তৈরি হয়েছে।

৮১. রিয়্যাক্ট রাউটার v6-এর কম্পোনেন্টগুলো কী কী?
<BrowserRouter>, <Routes>, <Route>, <Link>, <NavLink>, <Navigate>, <Outlet>

৮২. history-র push ও replace মেথডের উদ্দেশ্য কী?
push: নতুন এন্ট্রি যোগ করে

replace: বর্তমান এন্ট্রি প্রতিস্থাপন করে

৮৩. রিয়্যাক্ট রাউটার v4-এ কীভাবে প্রোগ্রামেটিক্যালি নেভিগেট করবেন?
useNavigate() হুক ব্যবহার করে: const navigate = useNavigate(); navigate('/home');

৮৪. রিয়্যাক্ট রাউটার v4-এ কীভাবে কোয়েরি প্যারামিটার পাবেন?
useLocation() হুক এবং new URLSearchParams(location.search) ব্যবহার করে।

৮৫. "Router may have only one child element" ওয়ার্নিং কেন পান?
<BrowserRouter>-এর সরাসরি ভেতরে একাধিক এলিমেন্ট থাকলে। সবকিছু <Routes> বা <div> দিয়ে র‍্যাপ করুন।

৮৬. রিয়্যাক্ট রাউটার v4-এ কীভাবে history.push-এ প্যারাম পাস করবেন?
navigate('/user/123', { state: { from: 'home' } }) অথবা পাথ প্যারামিটার।

৮৭. কীভাবে ডিফল্ট বা নটফাউন্ড পেজ ইমপ্লিমেন্ট করবেন?
পাথ * দিয়ে শেষ Route বানান: <Route path="*" element={<NotFound />} />

৮৮. রিয়্যাক্ট রাউটার v4-এ কীভাবে হিস্ট্রি পাবেন?
useNavigate() (v6) বা পুরনো ভার্সনে useHistory()।

৮৯. লগইনের পর কীভাবে অটোমেটিক রিডাইরেক্ট করবেন?
navigate('/dashboard', { replace: true }) ব্যবহার করে।

রিয়্যাক্ট ইন্টারন্যাশনালাইজেশন (React Intl) - ৯০ থেকে ৯৫
৯০. রিয়্যাক্ট ইন্টেল কী?
ফরম্যাটজেএসের রিয়্যাক্টের জন্য ইন্টারন্যাশনালাইজেশন (i18n) লাইব্রেরি। একাধিক ভাষা সাপোর্ট করে।

৯১. রিয়্যাক্ট ইন্টেলের প্রধান বৈশিষ্ট্যগুলো কী কী?

৯২. রিয়্যাক্ট ইন্টেলে ফরম্যাটিংয়ের দুটি উপায় কী কী?
কম্পোনেন্ট ভিত্তিক: <FormattedMessage />

হুক ভিত্তিক: useIntl()

৯৩. প্লেসহোল্ডার হিসেবে কীভাবে FormattedMessage ব্যবহার করবেন?
jsx

৯৪. রিয়্যাক্ট ইন্টেলে কীভাবে বর্তমান লোকেল অ্যাক্সেস করবেন?
useIntl() হুক থেকে locale প্রপ: const { locale } = useIntl();

৯৫. রিয়্যাক্ট ইন্টেলে কীভাবে তারিখ ফরম্যাট করবেন?

রিয়্যাক্ট টেস্টিং (React Testing) - ৯৬ থেকে ১০১
৯৬. রিয়্যাক্ট টেস্টিংয়ে শ্যালো রেন্ডারার কী?
একটি কম্পোনেন্টকে গভীরতা ছাড়া রেন্ডার করে (চাইল্ড কম্পোনেন্ট রেন্ডার হয় না)। ইউনিট টেস্টের জন্য।

৯৭. টেস্টরেন্ডারার প্যাকেজ কী?
react-test-renderer – রিয়্যাক্ট কম্পোনেন্টকে পিওর জাভাস্ক্রিপ্ট অবজেক্টে রেন্ডার করে (DOM ছাড়া)। স্ন্যাপশট টেস্টিংয়ে ব্যবহার হয়।

৯৮. ReactTestUtils প্যাকেজের উদ্দেশ্য কী?
রিয়্যাক্ট কম্পোনেন্ট টেস্টিংয়ের জন্য হেল্পার ফাংশন দেয় (যেমন Simulate.click, scryRenderedDOMComponentsWithTag)।

৯৯. জেস্ট কী?
ফেসবুক তৈরিকৃত জাভাস্ক্রিপ্ট টেস্টিং ফ্রেমওয়ার্ক। রিয়্যাক্টের সাথে ডিফল্ট হিসেবে আসে (CRA)।

১০০. জেসমিনের তুলনায় জেস্টের সুবিধাগুলো কী কী?

১৫৫. রিডাক্স কি শুধু রিয়্যাক্টের সাথে ব্যবহার করা যায়?

১৫৬. রিডাক্স ব্যবহারের জন্য কী নির্দিষ্ট বিল্ড টুল প্রয়োজন?
না। প্লেইন জাভাস্ক্রিপ্টেও ব্যবহার করা যায়।

১৫৭. রিডাক্স ফর্মের ইনিশিয়াল ভ্যালু কীভাবে স্টেট থেকে আপডেট হয়?
initialValues প্রপে ফাংশন পাস করে: initialValues={() => ({ name: store.name })}

১৫৮. রিয়্যাক্ট প্রপটাইপস কীভাবে এক প্রপের জন্য ভিন্ন ধরন অনুমতি দেয়?
PropTypes.oneOfType([PropTypes.string, PropTypes.number])

১৫৯. SVG ফাইল কি রিয়্যাক্ট কম্পোনেন্ট হিসেবে ইম্পোর্ট করতে পারবেন?
হাঁ। CRA-তে ডিফল্ট সাপোর্ট: import { ReactComponent as Logo } from './logo.svg'

১৬০. রেন্ডার হাইজ্যাকিং কী?
HOC বা রেন্ডার প্রপস দিয়ে কম্পোনেন্টের রেন্ডার আউটপুট ইন্টারসেপ্ট ও মডিফাই করা।

১৬১. কীভাবে রিয়্যাক্ট কম্পোনেন্টে সংখ্যা পাঠাবেন?
<MyComponent count={5} /> (কার্লি ব্রেসে সংখ্যা) অথবা count="5" দিলে স্ট্রিং যায়।

১৬২. সব স্টেট কি রিডাক্সে রাখা উচিত? কি কি রিয়্যাক্টের ইন্টারনাল স্টেটে রাখবেন?
শুধু গ্লোবাল ডেটা রিডাক্সে। লোকাল UI স্টেট (যেমন মোডাল খোলা/বন্ধ) রিয়্যাক্ট স্টেটে রাখুন।

১৬৩. registerServiceWorker-এর উদ্দেশ্য কী?
CRA-তে প্রগ্রেসিভ ওয়েব অ্যাপ (PWA) ফিচার দেয় – অফলাইন সাপোর্ট ও ক্যাশিং।

১৬৪. React.memo ফাংশন কী?
ফাংশনাল কম্পোনেন্ট মেমোইজেশন করে। প্রপস পরিবর্তন না হলে রি-রেন্ডার বাধা দেয়।

১৬৫. React.lazy ফাংশন কী?
কম্পোনেন্ট ডাইনামিক ইম্পোর্ট করে (কোড স্প্লিটিং)। Suspense-এর সাথে ব্যবহার হয়।

১৬৬. কীভাবে setState ব্যবহার করে অপ্রয়োজনীয় আপডেট প্রতিরোধ করবেন?
shouldComponentUpdate বা React.memo ব্যবহার করুন, অথবা useMemo/useCallback দিয়ে প্রপস স্থিতিশীল রাখুন।

১৬৯. হুকসের জন্য কী কী নিয়ম মেনে চলতে হবে?

১৭০. কীভাবে নিশ্চিত করবেন যে আপনার প্রকল্পে হুকসের নিয়ম অনুসরণ হয়?

১৭৫. রিয়্যাক্ট ১৬-এ আন্ডকট এররগুলোর আচরণ কী?

১৭৬. এরর বাউন্ডারির সঠিক স্থান কোথায়?

১৭৭. এরর বাউন্ডারি থেকে কম্পোনেন্ট স্ট্যাক ট্রেসের সুবিধা কী?
কোন কম্পোনেন্টে এরর হয়েছে তা দ্রুত চিহ্নিত করা যায়। প্রোডাকশনে ডিবাগ সহজ করে।

১৭৮. ডিফল্ট প্রপস কী?

১৮০. রিয়্যাক্ট অ্যাপ্লিকেশনের জন্য ব্রাউজার সাপোর্ট কী?
রিয়্যাক্ট ১৮+: IE নয়। আধুনিক ব্রাউজার (Chrome, Firefox, Safari, Edge)।

১৮১. কোড স্প্লিটিং কী?
বড় বান্ডলকে ছোট ছোট চাঙ্কে ভাগ করা যা প্রয়োজনে লোড হয়। React.lazy() + Suspense ব্যবহার করুন।

১৮২. কীড ফ্র্যাগমেন্টস কী?
ফ্র্যাগমেন্টে কী অ্যাট্রিবিউট দিতে চাইলে <Fragment key={id}> ব্যবহার করুন।

১৮৩. রিয়্যাক্ট কি সব HTML অ্যাট্রিবিউট সাপোর্ট করে?
বেশিরভাগ সাপোর্ট করে, তবে কিছু আলাদা (className, htmlFor)।

১৮৪. কম্পোনেন্ট প্রপস কখন ডিফল্ট true হয়?
প্রপস নাম লিখলে কিন্তু মান না দিলে: <MyComponent disabled /> -> disabled={true}

১৮৫. নেক্সট.জেএস কী এবং এর প্রধান বৈশিষ্ট্যগুলো কী কী?

১৮৬. কীভাবে একটি কম্পোনেন্টে ইভেন্ট হ্যান্ডলার পাস করবেন?

১৮৭. কীভাবে একটি ফাংশনকে একাধিকবার কল হওয়া থেকে রক্ষা করবেন?

১৮৮. JSX কীভাবে ইনজেকশন আক্রমণ প্রতিরোধ করে?

১৮৯. কীভাবে রেন্ডার করা এলিমেন্ট আপডেট করবেন?
স্টেট পরিবর্তন করুন। রিয়্যাক্ট স্বয়ংক্রিয়ভাবে রি-রেন্ডার করবে।

১৯০. প্রপস রিড-অনলি তা কীভাবে নির্দেশ করবেন?

২৪৭. স্ট্রিক্ট মোড কেন দুবার রেন্ডার করে?
অপবিত্র রিডিউসার ও সাইড ইফেক্ট সনাক্ত করতে। প্রোডাকশনে একবারই রেন্ডার হয়।

২৪৮. JSX-এর নিয়মগুলো কী কী?
একটি রুট এলিমেন্ট লাগে (ফ্র্যাগমেন্ট ব্যবহার করতে পারেন)

সব ট্যাগ বন্ধ করতে হবে

camelCase অ্যাট্রিবিউট

className ব্যবহার করুন

২৪৯. একাধিক JSX ট্যাগ কেন র‍্যাপ করতে হয়?
কারণ JSX শুধু একটি এক্সপ্রেশন রিটার্ন করতে পারে। ফ্র্যাগমেন্ট বা div দিয়ে র‍্যাপ করলে একটি এক্সপ্রেশন হয়।

২৫০. অ্যারে ভেরিয়েবল মিউটেশন কীভাবে প্রতিরোধ করবেন?
স্প্রেড অপারেটর ([...arr]), concat(), filter(), map() ব্যবহার করুন (এরা নতুন অ্যারে রিটার্ন করে)।

২৫১. ক্যাপচার ফেজ ইভেন্ট কী?
DOM ইভেন্টের ক্যাপচার ফেজে ইভেন্ট হ্যান্ডলার চালাতে ইভেন্ট নামের শেষে Capture যোগ করুন: onClickCapture।

২৫২. রিয়্যাক্ট কীভাবে স্ক্রিন আপডেট করে?
স্টেট পরিবর্তন → ভার্চুয়াল DOM ডিফ → রিকনসিলিয়েশন → শুধু পরিবর্তিত অংশ রিয়েল DOM-এ কমিট।

২৫৩. রিয়্যাক্ট কীভাবে একাধিক স্টেট আপডেট ব্যাচ করে?
এক ইভেন্ট হ্যান্ডলারের ভেতরের সব setState একত্র করে একবারে রি-রেন্ডার করে।

২৫৪. স্বয়ংক্রিয় ব্যাচিং প্রতিরোধ করা সম্ভব?
হাঁ। flushSync ব্যবহার করে: flushSync(() => setCount(c => c+1))

২৫৫. রিয়্যাক্ট হাইড্রেশন কী?
SSR-এ সার্ভার থেকে আসা HTML-এর সাথে রিয়্যাক্ট ইভেন্ট লিসেনার অ্যাটাচ করার প্রক্রিয়া।

২৫৬. স্টেটের ভেতর অবজেক্ট কীভাবে আপডেট করবেন?
স্প্রেড অপারেটর: setUser({...user, name: 'নতুন নাম'})

২৫৭. স্টেটের ভেতর নেস্টেড অবজেক্ট কীভাবে আপডেট করবেন?
প্রতিটি স্তরে স্প্রেড করুন: setState({...state, address: {...state.address, city: 'ঢাকা'}})

২৫৮. স্টেটের ভেতর অ্যারে কীভাবে আপডেট করবেন?
যোগ: [...arr, newItem]

মুছ: arr.filter(i => i !== id)

আপডেট: arr.map(i => i.id === id ? {...i, name} : i)

২৫৯. স্টেট আপডেটের জন্য ইমার লাইব্রেরি কীভাবে ব্যবহার করবেন?
produce ফাংশন দিয়ে ড্রাফটে মিউটেট করুন:

jsx
setState(produce(draft => { draft.name = 'নতুন' }))
২৬০. সরাসরি স্টেট মিউটেশন প্রতিরোধের সুবিধাগুলো কী কী?
টাইম ট্রাভেল ডিবাগিং

রি-রেন্ডার অপটিমাইজেশন

বাগ কমায়

প্রেডিক্টেবিলিটি

২৬১. স্টেট আপডেটের জন্য পছন্দনীয় ও অ-পছন্দনীয় অ্যারে অপারেশনগুলো কী কী?
পছন্দনীয়	অ-পছন্দনীয়
map, filter, concat, spread	push, pop, shift, unshift, splice
২৬২. নেস্টেড ফাংশন কম্পোনেন্ট ডিফাইন করলে কী হবে?
প্রতি রি-রেন্ডারে ফাংশন রি-ক্রিয়েট হয়। পারফরম্যান্স খারাপ হয় এবং স্টেট রিসেট হয়।

২৬৩. নন-লিস্ট আইটেমের জন্য কী ব্যবহার করতে পারি?
হাঁ। কী যেকোনো জায়গায় ব্যবহার করা যায়, বিশেষ করে অ্যানিমেশন বা ফর্ম ক্ষেত্র চিহ্নিত করতে।

২৬৪. রিডিউসার লেখার জন্য নির্দেশিকাগুলো কী কী?
স্টেট ও অ্যাকশনের উপর ভিত্তি করে নতুন স্টেট রিটার্ন করুন

কখনো মিউটেট করবেন না

সাইড ইফেক্ট করবেন না (API কল, ডেট ফাংশন)

হুকস (Hooks) - ২৬৫ থেকে ৩১৯
২৬৫. useReducer হুক কী? এর ব্যবহার বর্ণনা করতে পারেন?
জটিল স্টেট লজিকের জন্য useState-এর বিকল্প। একটি রিডিউসার ফাংশন নেয় এবং বর্তমান স্টেট ও ডিস্প্যাচ ফাংশন রিটার্ন করে।

২৬৬. useState ও useReducer কীভাবে তুলনা করবেন?
useState	useReducer
সরল (বুলিয়ান, নাম্বার, স্ট্রিং)	জটিল (অবজেক্ট, অ্যারে)
নিকটবর্তী স্টেট	পরবর্তী স্টেট পূর্ববর্তীর উপর নির্ভরশীল
২৬৭. useContext হুকের সাথে কনটেক্সট কীভাবে কাজ করে?
কনটেক্সটের বর্তমান মান পড়তে useContext(MyContext) ব্যবহার করুন। কনটেক্সট পরিবর্তন হলে কম্পোনেন্ট রি-রেন্ডার হয়।

২৬৮. useContext হুকের ব্যবহারের ক্ষেত্রগুলো কী কী?
থিম (ডার্ক/লাইট)

ভাষা (i18n)

প্রমাণীকরণ (ইউজার ডেটা)

গ্লোবাল কনফিগারেশন

২৬৯. কখন ক্লায়েন্ট ও সার্ভার কম্পোনেন্ট ব্যবহার করবেন?
সার্ভার কম্পোনেন্ট: স্ট্যাটিক কনটেন্ট, ডাটাবেস অ্যাক্সেস
ক্লায়েন্ট কম্পোনেন্ট: ইন্টারঅ্যাকটিভ UI, হুকস, ইভেন্ট লিসেনার

২৭০. নেক্সট.জেএস-এর পেজ রাউটার ও অ্যাপ রাউটারের মধ্যে পার্থক্যগুলো কী কী?
পেজ রাউটার	অ্যাপ রাউটার
পেজ ডিরেক্টরি	অ্যাপ ডিরেক্টরি
getServerSideProps	সার্ভার কম্পোনেন্ট ডিফল্ট
ঐতিহ্যবাহী	রিয়্যাক্ট ১৮+ ফিচার
২৭১. useMemo() হুক বর্ণনা করতে পারেন?
ব্যয়বহুল গণনার ফলাফল মেমোয়েজ করে। নির্ভরশীলতা পরিবর্তিত হলেই শুধু পুনঃগণনা করে।

২৭২. হুকস কি ক্লাস কম্পোনেন্টে ব্যবহার করা যায়?
না। হুকস শুধুমাত্র ফাংশনাল কম্পোনেন্ট বা কাস্টম হুকসে ব্যবহার করা যায়।

২৭৩. আপডেটার ফাংশন কী? সব ক্ষেত্রে কি আপডেটার ফাংশন ব্যবহার করা উচিত?
setCount(c => c + 1) - আপডেটার ফাংশন। পূর্ববর্তী স্টেটের উপর নির্ভরশীল আপডেটের জন্য ব্যবহার করবেন।

২৭৪. useState কি ফাংশন ইনিশিয়াল ভ্যালু নিতে পারে?
হাঁ। লেজি ইনিশিয়ালাইজেশন: useState(() => expensiveComputation())

২৭৫. useState কী কী ধরনের মান ধারণ করতে পারে?
যেকোনো জাভাস্ক্রিপ্ট টাইপ: নাম্বার, স্ট্রিং, বুলিয়ান, অ্যারে, অবজেক্ট, এমনকি ফাংশন।

২৭৬. useState কে শর্তসাপেক্ষে কল করলে কী হবে?
হুকসের নিয়ম ভঙ্গ হবে। রিয়্যাক্ট ওয়ার্নিং দেবে এবং আচরণ অনির্ধারিত হবে।

২৭৭. useState কি সিঙ্ক্রোনাস নাকি অ্যাসিঙ্ক্রোনাস?
আপডেট ব্যাচিংয়ের কারণে অ্যাসিঙ্ক্রোনাস। সঙ্গে সঙ্গেই মান পাওয়া যাবে না।

২৭৮. useState কীভাবে ভিতরে কাজ করে ব্যাখ্যা করতে পারেন?
প্রতিটি কম্পোনেন্টের জন্য রিয়্যাক্ট একটি "মেমোরি সেল" রাখে। ক্রম অনুযায়ী হুক কল সংরক্ষণ করে।

২৭৯. useReducer কী? কেন useReducer ব্যবহার করবেন?
একটি হুক যা রিডিউসার প্যাটার্ন ইমপ্লিমেন্ট করে। জটিল স্টেট ট্রানজিশন (একাধিক সাব-ভ্যালু) থাকলে ব্যবহার করুন।

২৮০. useReducer কীভাবে কাজ করে? উদাহরণসহ ব্যাখ্যা করুন?
jsx
const reducer = (state, action) => {
  switch(action.type) {
    case 'increment': return {count: state.count + 1};
    default: return state;
  }
};
const [state, dispatch] = useReducer(reducer, {count: 0});
২৮১. useReducer কি useContext এর সাথে একত্রিত করতে পারেন?
হাঁ। রিডিউসার স্টেট ও ডিস্প্যাচ কনটেক্সটে রেখে ডিপ কম্পোনেন্টে অ্যাক্সেস দেওয়া যায়।

২৮২. useReducer দিয়ে কি একের পর এক একাধিক অ্যাকশন ডিস্প্যাচ করতে পারেন?
হাঁ। প্রতিটি ডিস্প্যাচের জন্য রিডিউসার চালাবে এবং শেষে ব্যাচ আপডেট হবে।

২৮৩. useReducer থেকে ডিস্প্যাচ কি অ্যাসিঙ্ক্রোনাস এবং তাৎক্ষণিক স্টেট আপডেট করে?
ডিস্প্যাচ কল স্টেট আপডেটের জন্য অনুরোধ করে। আপডেট ব্যাচিংয়ের কারণে স্টেট অবিলম্বে পরিবর্তন হয় না।

২৮৪. useContext কীভাবে কাজ করে? উদাহরণসহ ব্যাখ্যা করুন?
jsx
const ThemeContext = React.createContext('light');
const theme = useContext(ThemeContext); // 'light' বা প্রোভাইডার থেকে মান
২৮৫. এক কম্পোনেন্টে কি একাধিক কনটেক্সট ব্যবহার করতে পারেন?
হাঁ। একাধিকবার useContext কল করতে পারেন, ভিন্ন ভিন্ন কনটেক্সটের জন্য।

২৮৬. অবজেক্টের সাথে useContext ব্যবহারের একটি সাধারণ ফাঁদ কী কী?
কনটেক্সট মান একটি অবজেক্ট হলে, প্রোভাইডারের মান পরিবর্তন না করলেও, প্যারেন্ট রি-রেন্ডারে সব কনজিউমার রি-রেন্ডার হয়। মেমোাইজেশন ব্যবহার করুন।

২৮৭. কোনো ম্যাচিং প্রোভাইডার না থাকলে কনটেক্সট ভ্যালু কী হবে?
createContext()-এ দেওয়া ডিফল্ট ভ্যালু।

২৮৮. useEffect ডিপেন্ডেন্সি অ্যারেতে রিঅ্যাকটিভ ডিপেন্ডেন্সি কীভাবে এক্সিকিউশন আচরণ প্রভাবিত করে?
ডিপেন্ডেন্সিগুলোর মধ্যে যে কোনো একটি পরিবর্তিত হলে ইফেক্ট পুনরায় চলে। খালি অ্যারে দিলে শুধু মাউন্টে একবার চলে।

২৮৯. কখন এবং কতবার React useEffect-এর ভেতরের সেটআপ ও ক্লিনআপ ফাংশন ডাকে?
প্রতি রেন্ডারে ডিপেন্ডেন্সি তুলনা করে। পরিবর্তন পেলে আগের ক্লিনআপ, তারপর নতুন সেটআপ চালায়।

২৯০. useEffect থেকে Promise রিটার্ন করলে কী হবে?
এরর দেবে। ক্লিনআপ ফাংশন একটি ফাংশন রিটার্ন করবে, প্রমিস নয়।

২৯১. একটি কম্পোনেন্টে কি একাধিক useEffect থাকতে পারে?
হাঁ। যুক্তি অনুযায়ী ভাগ করে নিন। এরা ক্রমান্বয়ে চলে।

২৯২. useEffect দিয়ে কীভাবে ইনফিনিট লুপ প্রতিরোধ করবেন?
ডিপেন্ডেন্সি অ্যারে সঠিক দিন এবং ইফেক্টের ভেতর স্টেট আপডেট করলে শর্তসাপেক্ষে করুন।

২৯৩. useLayoutEffect-এর ব্যবহারের ক্ষেত্রগুলো কী কী?
DOM এলিমেন্টের অবস্থান/সাইজ মাপা

স্ক্রল পজিশন সামঞ্জস্য

ফ্লিকারিং প্রতিরোধ

২৯৪. সার্ভার-সাইড রেন্ডারিংয়ে (SSR) useLayoutEffect কীভাবে কাজ করে?
Warning দেয়। সার্ভারে চলে না, শুধু ক্লায়েন্টে চলে।

২৯৫. নন-লেআউট লজিকের জন্য useLayoutEffect ব্যবহার করলে কী হবে?
অপ্রয়োজনীয় ব্লকিং হবে। ব্রাউজার পেইন্ট আটকে যাবে, পারফরম্যান্স খারাপ হবে।

২৯৬. useLayoutEffect কীভাবে লেআউট থ্রাশিং সৃষ্টি করে?
বারবার DOM মাপা ও সেট করার কারণে ব্রাউজার বারবার রি-ফ্লো করে।

২৯৭. DOM এলিমেন্ট অ্যাক্সেস করতে useRef কীভাবে ব্যবহার করবেন? উদাহরণ দিন?
jsx
const inputRef = useRef();
<input ref={inputRef} />
inputRef.current.focus();
২৯৮. useRef কি রেন্ডার জুড়ে মান ধরে রাখতে পারে?
হাঁ। স্টেটের মতো কিন্তু পরিবর্তন করলে রি-রেন্ডার হয় না।

২৯৯. useRef কি পূর্বের মান সংরক্ষণ করতে পারে?
হাঁ। useRef দিয়ে পূর্বের প্রপস/স্টেট সংরক্ষণ করে তুলনা করতে পারেন।

৩০০. রেন্ডার মেথডে কি রেফ অ্যাক্সেস করা সম্ভব?
না। রেন্ডারের সময় DOM এখনও তৈরি হয়নি। useEffect বা ইভেন্ট হ্যান্ডলারে অ্যাক্সেস করুন।

৩০১. useRef হুকের সাধারণ ব্যবহারের ক্ষেত্রগুলো কী কী?
DOM এলিমেন্টে ফোকাস

টাইমার আইডি সংরক্ষণ

পূর্বের মান ট্র্যাকিং

ইম্পেরেটিভ মেথড কল

৩০২. useImperativeHandle হুক কী? উদাহরণ দিন?
প্যারেন্ট কম্পোনেন্টকে চাইল্ডের ইম্পেরেটিভ মেথড অ্যাক্সেস দিতে forwardRef-এর সাথে ব্যবহার হয়।

jsx
useImperativeHandle(ref, () => ({ focus: () => inputRef.current.focus() }));
৩০৩. কখন useImperativeHandle ব্যবহার করবেন?
থার্ড-পার্টি লাইব্রেরি ইন্টিগ্রেশন, অ্যানিমেশন ট্রিগার, ফাংশনাল কম্পোনেন্টে মেথড এক্সপোজ করতে।

৩০৪. forwardRef ছাড়া কি useImperativeHandle ব্যবহার করা যায়?
না। useImperativeHandle-কে একটি ref দরকার যা forwardRef থেকে আসে।

৩০৫. useMemo কীভাবে useCallback থেকে আলাদা?
useMemo	useCallback
মান মেমোয়েজ করে	ফাংশন মেমোয়েজ করে
useMemo(() => value, deps)	useCallback(fn, deps)
৩০৬. useMemo কি চাইল্ড কম্পোনেন্টের রি-রেন্ডার প্রতিরোধ করে?
পরোক্ষভাবে করে। যদি মেমোয়েজড মান প্রপস হিসেবে যায় এবং তা পরিবর্তন না হয়, তবে চাইল্ড রি-রেন্ডার হয় না।

৩০৭. useCallback কী এবং কেন ব্যবহার করা হয়?
ফাংশন মেমোয়েজ করে, যাতে ডিপেন্ডেন্সি পরিবর্তন না হলে একই ফাংশন রেফারেন্স থাকে। চাইল্ড কম্পোনেন্টে অপ্রয়োজনীয় রি-রেন্ডার বাধা দেয়।

৩০৮. কাস্টম রিয়্যাক্ট হুকস কী এবং কীভাবে তৈরি করবেন?
রিইউজেবল লজিকের ফাংশন যার নাম use দিয়ে শুরু হয়। যেমন:

jsx
function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);
  // ...
  return width;
}
৩০৯. রিয়্যাক্ট ফাইবার কীভাবে কাজ করে? বিস্তারিত ব্যাখ্যা দিন?
ফাইবার একটি ভির্চুয়াল DOM নোড। ফাইবার আর্কিটেকচার কাজকে ছোট ইউনিটে ভাগ করে, প্রাধান্য দেয়, থামাতে ও পুনরায় শুরু করতে পারে। এটি কাজের একটি লিংকড লিস্ট মেইনটেইন করে।

৩১০. useId হুক কী এবং কখন ব্যবহার করবেন?
সার্ভার ও ক্লায়েন্টের মধ্যে কনসিস্টেন্ট ইউনিক আইডি জেনারেট করে। অ্যাক্সেসিবিলিটি অ্যাট্রিবিউটের (যেমন aria-labelledby) জন্য ব্যবহার করুন।

৩১১. useDeferredValue হুক কী?
UI-তে একটি ডিফারড (বিলম্বিত) সংস্করণ দেখায়। নন-আরজেন্ট আপডেটকে পিছিয়ে দেয়, যেমন ফিল্টারিং।

৩১২. useTransition হুক কী এবং useDeferredValue থেকে কীভাবে আলাদা?
useTransition একটি isPending ফ্ল্যাগ দেয়। আলাদা:

useTransition: সেটস্টেট ফাংশনকে ট্রানজিশনে র‍্যাপ করে

useDeferredValue: মানকে ডিফার করে

৩১৩. useSyncExternalStore হুক কী?
বাহ্যিক স্টোর (যেমন Redux, Zustand) থেকে সিঙ্ক্রোনাসভাবে মান পড়ার হুক।

৩১৪. useInsertionEffect হুক কী?
CSS-in-JS লাইব্রেরির জন্য। DOM মিউটেশনের আগে স্টাইল ইনজেক্ট করে। লেআউট ইফেক্টের পর চলে।

৩১৫. কীভাবে কাস্টম হুক ব্যবহার করে কম্পোনেন্টের মধ্যে স্টেট লজিক শেয়ার করবেন?
স্টেট, ইফেক্ট, রেফ ইত্যাদি কাস্টম হুকের ভেতর রেখে তা একাধিক কম্পোনেন্টে ব্যবহার করুন।

৩১৬. useDebugValue হুক কী?
ডেভ টুলসে কাস্টম হুকের লেবেল প্রদর্শন করতে।

৩১৭. useEffect-এ কীভাবে ক্লিনআপ হ্যান্ডেল করবেন?
রিটার্ন একটি ফাংশন করুন:

jsx
useEffect(() => {
  const timer = setInterval(...);
  return () => clearInterval(timer);
}, []);
৩১৮. useEffect ও experimental useEvent-এর মধ্যে পার্থক্য কী?
useEvent ডিপেন্ডেন্সি পরিবর্তন ছাড়াই সর্বশেষ প্রপস/স্টেট অ্যাক্সেস করে। এটি কখনো পরিবর্তিত হয় না।
